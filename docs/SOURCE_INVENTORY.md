## Version selection
Each project folder holds one description file, so there were no competing versions. The only exception is RETINA, where `RetinaMFA.docx` (study draft, working folder) sits beside the folder's short `RETINA description.pdf`. The site uses both, with the draft's abstract and research questions.

## Conflicts found
1. **HYDRA**: the written description covers eye images + MAX30102 + SVM; the concept infographic adds urine-strip analysis and water dispensing. Site treats the latter as concept only.
2. **Skin project**: the description speaks of CNN models; the screenshot shows a classical image-processing pipeline. Site states both and does not link them.
3. **Names**: folder and UI names differ for SAFARIS, VISION, RETINA/RetinaMFA and the MATLAB project. Both names are shown on each project page.
4. **HYSEIS**: the screenshot labels a fault entry "(placeholder)". Mentioned under limitations.
5. **Résumé email vs your account email**: the résumé lists `pjfreelance02@gmail.com`; that address is used on the site.
